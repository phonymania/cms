# 1ファイル・ブログCMS (PHP + SQLite)

`index.php` を1つ置いてアクセスするだけで動く、WordPress風のブログCMSです。
データベースの設定は不要で、初回アクセス時に初期設定画面が表示されます。

## 動作環境

- PHP **8.1 以上**
- PHP拡張: `pdo_sqlite`(必須) / `mbstring`(無くても動作します)
- Apache 推奨(`.htaccess` を使います)。nginx でも動作しますが、後述の設定が必要です
- HTTPS での運用を強く推奨します

## インストール

1. `index.php` をサーバーの公開ディレクトリにアップロードします
2. ブラウザで `https://あなたのサイト/index.php` を開きます
3. 初期設定画面でブログ名・管理者ユーザー名・パスワードを入力します
   - ユーザー名: 半角英数字と `_` `-` の 3〜32 文字
   - パスワード: 12 文字以上
4. 作成後、ログイン画面(`?a=login`)からログインします

`data/`(データベース)と `uploads/`(画像)は初回アクセス時に自動作成されます。
ディレクトリへの書き込み権限が必要です。

### アップデート

新しい `index.php` で上書きするだけです。`data/` と `uploads/` はそのまま使えます。
データベースの構造は起動時に自動で更新されます。

## ファイル構成

```
index.php      本体(これだけでOK)
data/          SQLiteデータベース(自動作成。外部アクセス拒否)
uploads/       アップロード画像(自動作成)
plugins/       プラグイン置き場(任意。*.php を自動読込)
.htaccess      「綺麗なURL」をONにしたときのみ自動生成
```

## 機能

- 記事 / 固定ページの作成・編集・削除、下書き / 公開
- カテゴリ、タグ、キーワード検索、ページ送り
- コメント(承認制 / 即時公開を選択、スパム対策付き)
- 画像アップロード(メディア管理)
- RSS フィード(`?a=feed`)
- パスワード変更
- 見た目の改造(設定画面)・プラグイン
- 綺麗なURL(`/post/1` 形式、任意)

## 管理画面

ログイン後、画面上部の「管理」から利用できます。

| メニュー | 内容 |
| --- | --- |
| 記事 | 記事一覧、編集、削除 |
| 新規 | 記事 / 固定ページの作成 |
| メディア | 画像のアップロード・削除 |
| コメント | 承認・削除 |
| 設定 | サイト設定、見た目の改造 |
| パスワード | 管理者パスワードの変更 |

## 記事の書き方 (Markdown)

| 書き方 | 結果 |
| --- | --- |
| `# 見出し` / `## 見出し` / `### 見出し` | 見出し |
| `**太字**` | 太字 |
| `*斜体*` | 斜体 |
| `` `code` `` | インラインコード |
| `[文字](https://example.com)` | リンク(http / https のみ) |
| `![説明](uploads/ファイル名)` | 画像(メディアにアップロードしたもののみ) |
| `- 項目` | 箇条書き(連続した行) |
| 空行 | 段落の区切り |

HTMLは書けません(すべてエスケープされます)。外部サイトの画像は埋め込めません。

## 見た目の改造

「設定」画面から次の項目を変更できます。

- ブログ名、サブタイトル、ヘッダー画像(`uploads/…` のパス)
- テーマ(light / dark / sepia)、アクセント色、フォント(sans / serif / mono)、本文幅
- サイドバーの位置(右 / 左 / なし)
- ウィジェットの表示と順序(カンマ区切り): `about,search,recent,cats,tags`
- メニュー(1行1件、`名前|URL` 形式。URLは `http(s)://`、`/`、`?`、`#` で始まるもの)
- About、フッター(Markdown)
- カスタムCSS
- 1ページの記事数、コメントの許可 / 承認制、URL形式

公開済みの固定ページは、自動でメニューに追加されます。

## プラグイン

`plugins/` フォルダに `*.php` を置くと自動で読み込まれます。
`add_hook()` で次のフックに処理を追加できます。

| フック名 | 引数 | 役割 |
| --- | --- | --- |
| `post_html` | `$html, $post` | 記事本文のHTMLを加工して返す |
| `sidebar` | `$html` | サイドバーのHTMLを加工して返す |
| `footer` | `$html` | フッターに追加するHTMLを返す |
| `css` | `$css` | 出力するCSSを加工して返す |
| `route` | `$out, $action` | 独自ページの追加(HTML文字列を返すと表示) |

例: `plugins/hello.php`

```php
<?php
// フッターに文言を追加
add_hook('footer', fn($v) => $v . '<p>Powered by My CMS</p>');

// ?a=hello で独自ページを表示
add_hook('route', fn($v, $a) => $a === 'hello' ? '<h2>Hello</h2><p>こんにちは</p>' : $v);
```

> **注意**: プラグインはPHPの全権限で動きます。信頼できるものだけを置いてください。
> プラグインが出力するHTMLのエスケープは、プラグイン側の責任です。

## 綺麗なURL

「設定」→「URL形式」を `/post/1` にして保存すると、`.htaccess` が自動生成されます。
`mod_rewrite` が有効で、`AllowOverride` が許可されている必要があります。
動作しない場合は、`index.php?a=settings` から元に戻してください。

### nginx の場合(未検証の設定例)

`.htaccess` が使われないため、`data/` の保護とURL書き換えを自分で設定します。

```nginx
location ^~ /data/ { deny all; }
location ~* ^/uploads/.*\.(php|phtml|phar|html?)$ { deny all; }

rewrite ^/post/([0-9]+)/?$ /index.php?a=post&id=$1 last;
```

## セキュリティ対策

- SQL: すべてプリペアドステートメント
- XSS: 出力は常にエスケープ。Markdownは先にエスケープしてから安全なタグだけ生成。CSP(nonce)でスクリプトや外部読み込みを遮断
- CSRF: すべてのPOSTにトークン検証。ログアウト・削除もPOSTのみ
- 認証:
  - パスワードは `password_hash` で保存
  - ログイン時にセッションIDを再生成
  - Cookie は `HttpOnly` / `SameSite=Lax`(HTTPSでは `Secure` と `__Host-` も付与)
  - 無操作2時間で自動ログアウト
  - 同一IPからのログイン失敗が15分間に5回でロック
- コメント: ハニーポット + 同一IPからの投稿制限(15分に3件まで)
- アップロード: 画像の中身を検査し、JPEG / PNG / GIF / WebP のみ・5MB以下。ファイル名はランダム化し、`uploads/` 内でのスクリプト実行は拒否
- その他: `X-Frame-Options`、`X-Content-Type-Options`、`Referrer-Policy`、HSTS(HTTPS時)
- `data/` はアクセス拒否 + DBファイル名はランダム

CSPの影響で、カスタムCSSから外部フォントや外部画像は読み込めません。

## バックアップ

`data/` と `uploads/` をコピーしてください。復元は同じ場所に戻すだけです。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 真っ白な画面 / 500エラー | PHPが8.1以上か、`pdo_sqlite` が有効か。エラー画面は出ない設定なので、サーバーのエラーログを確認 |
| 初期設定が保存できない | 設置ディレクトリに書き込み権限があるか |
| 画像がアップロードできない | 形式(JPEG/PNG/GIF/WebP)と5MB以下か。`uploads/` が書き込み可能か |
| 綺麗なURLで404になる | `mod_rewrite` / `AllowOverride` を確認。または設定で元の形式に戻す |
| パスワードを忘れた | 下記の手順で再設定 |

### パスワードの再設定

1. ハッシュを生成します
   ```
   php -r 'echo password_hash("新しいパスワード12文字以上", PASSWORD_DEFAULT);'
   ```
2. `data/db_*.sqlite` を SQLite ツールで開き、実行します
   ```sql
   UPDATE users SET pass = '生成したハッシュ' WHERE id = 1;
   ```

## 制限事項

- 管理者は1人のみ(複数ユーザー・権限管理なし)
- 記事のインポート / エクスポート、サイトマップは未対応
- タイムゾーンは `Asia/Tokyo` 固定(`index.php` 冒頭の `date_default_timezone_set` で変更可)
